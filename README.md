# 🏫 Agenda de Eventos Escolar

Projeto desenvolvido para a criação de uma Agenda de Eventos Escolar utilizando HTML5, CSS3 e JavaScript.

## 📅 Sobre o projeto

O site permite que alunos e professores consultem os eventos da escola, pesquisem atividades, filtrem eventos por categoria e realizem inscrições.

## 🚀 Funcionalidades

- Cadastro visual de eventos
- 8 eventos escolares
- Categorias de eventos
- Pesquisa de eventos
- Filtro por categoria
- Tabela de eventos
- Visualização de detalhes
- Formulário de inscrição
- Contador para o próximo evento
- Área de contato
- Layout responsivo
- Compatibilidade com computador e celular

## 💻 Tecnologias

- CSS3

## 🌐 Publicação no GitHub Pages

1. Criar um repositório público chamado `agenda-eventos`.
2. Enviar os arquivos do projeto para o repositório.
3. Acessar:

Settings → Pages

4. Em "Build and deployment", selecionar:

Deploy from a branch

5. Selecionar a branch `main` e a pasta `/root`.
6. Salvar.
7. Aguardar a publicação do site.
